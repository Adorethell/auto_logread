---
name: log_analysis
description: 当用户要求对anomalies_translated文件夹下的日志进行分析的时候使用
---

执行步骤：
1. 打开anomalise_translated文件夹。
2. 将文件夹下的每一个子文件夹视为一次独立的统计单元（例如一次测试运行或一个批次）。
3. 对于每个子文件夹，将其中的每一个文件视为一次异常记录。
4. 对每个异常文件进行分析：
   - 读取文件内容，分析异常类型、发生时间、关键错误信息等。
   - 详细分析异常的特征。
5. 将每次异常的分析结果记录到其所属的统计单元中，形成该单元的异常明细列表。
6. 根据example/example.csv和example/example.html文件为例子，生成最终报告：
   - 输出一个汇总.csv表格文件，展示每个统计单元的异常数量、异常文件、异常日志数据，异常原因，并根据日志含有的时间戳信息记录时间。
   - 同时输出一个HTML格式的报告文件，在表格基础上嵌入每个异常的详细分析内容，确保用户能直观查看整体统计与个体分析。
   - 将汇总excel表格文件和HTML格式的报告文件保存至claude_log_analysis文件夹。
7. 报告需清晰易读，同时体现每次异常的具体分析。

注意：异常文件可能包含重复信息，休眠数据等，分析时应提取核心信息，避免无关细节，同时不要生成脚本，只输出表格文件和htmi报告到claude_log_analysis文件夹。
